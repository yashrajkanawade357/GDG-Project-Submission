GDG Tech Wildcard  /  Frontend, task 1

Change it in one tab.
Every other tab already knows.

Tandem keeps your theme, language and text size identical across every open tab. A change reaches the others in about a millisecond, survives closing the browser, and two tabs editing at the same moment always settle on the same answer.

Spec sheet

What it does, and the numbers measured on a real run.

Delivery
BroadcastChannel to every same-origin tab, with the storage event as a second path when the first is missing or misses something.
Latency
1.29 ms average, 4.10 ms worst case, over 64 edits across three tabs. The brief asks for under 100 ms.
Conflicts
Every setting carries its own stamp from a hybrid logical clock. The newest write wins and the tab id breaks exact ties, so every tab picks the same winner on its own. A theme change and a language change made at the same instant both survive.
First paint
An inline script reads the saved preferences before anything is drawn. A dark-mode user never sees a white frame.
Languages
English, हिन्दी, Español, Français, Deutsch, 日本語.
Tests
66, including randomized four-tab runs where messages arrive out of order or get lost.

Try it in a minute

  1. Open the app twice. Two windows side by side work best, but tabs are fine.
  2. Drag the text-size slider in one. The other follows the thumb, and its monitor shows how long each change took to arrive.
  3. Press “Run drill”. Every open tab writes a different size at the same instant. Watch them agree on a single winner.
